About IdentForge

IdentForge is a tool for generating temporary identities and emails. You can create fake profiles including names, addresses, phone numbers, and disposable email accounts quickly and efficiently.

Main Features

  • Generate fake personal information such as names, addresses, and birth dates.
  • Create temporary email addresses for testing and quick sign-ups.
  • Copy generated identities to the clipboard with a single click.
  • Support multiple country formats.
  • Simple and lightweight desktop GUI.

Technologies

  • Python 3
  • PySide6 (GUI)
  • Random data generators
