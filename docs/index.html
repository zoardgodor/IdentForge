About IdentForge

IdentForge is a tool for generating temporary identities and emails. You can create fake profiles including names, addresses, phone numbers, and disposable email accounts quickly and efficiently.

Main Features

  • Generate fake personal information (name, address, date of birth, etc.)
  • Create temporary email addresses for testing or sign-ups
  • Copy generated identities to clipboard with one click
  • Supports multiple country formats
  • Simple and lightweight GUI

Technologies

  • Python 3
  • PySide6 (GUI)
  • Random data generators
